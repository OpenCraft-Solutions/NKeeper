# Security policy

NKeeper stores credentials for, and opens connections to, privileged infrastructure. We take vulnerability reports seriously.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately through GitHub instead:

1. Open the repository's **[Security](https://github.com/OpenCraft-Solutions/NKeeper/security)** tab.
2. Choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the impact you expect. We'll acknowledge the report, keep you updated as we investigate, and credit you in the advisory unless you'd rather we didn't.

## Supported versions

| Version | Supported |
| --- | --- |
| 2.0 (this repository, in development) | Reports welcome. There is no release yet. |
| 1.x | Report through [its own repository](https://github.com/DHemken97/NKeeper). |
