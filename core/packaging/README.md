# NKeeper SDK packages

Published by the [NKeeper](https://github.com/OpenCraft-Solutions/NKeeper) repository to GitHub Packages, versioned with the plugin SDK:

- `NKeeper.Abstractions`: the backend SDK.
- `NKeeper.Plugin.Build`: builds, packs and signs a plugin.
- `NKeeper.Testing`: the test server and fixtures for plugin tests.
- `@opencraft-solutions/nkeeper-sdk` (npm): the frontend SDK.

See `docs/architecture.md` §9 in the repository.
